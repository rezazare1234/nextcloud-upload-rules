# Security

Only version 3.x targeting Nextcloud 34 is currently declared compatible. This is a compatibility statement, not a guarantee of security support or a response-time commitment.

Do not publish credentials, private server URLs, user lists or exploit details in public issues. If this repository has GitHub private vulnerability reporting enabled, use Security → Report a vulnerability. Otherwise contact the repository owner privately before sharing sensitive details.

Administrators can configure policies and search the directory. Non-admin users and guests receive only their effective upload rules, without targeting or exclusion IDs. Browser validation is supplemented by server-side WebDAV checks. Filename restrictions do not inspect MIME types or file contents and are not malware protection.
